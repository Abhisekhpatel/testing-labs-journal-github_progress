## 📘 1. Summary of the Task
Describe the purpose of this activity in your own words:  
- What is the goal of the lab?  
- What network are you expected to create?

The purpose of this activity is to learn how computer networks are created and connected. The goal of the lab is to understand how devices communicate with each other through a network and how network configurations work in real life. During the lab, we are expected to create a small network using devices such as computers, switches, routers, or a Raspberry Pi. We also learn how to assign IP addresses, test connections between devices, and make sure the network is working correctly.

This activity helps develop practical skills in networking, troubleshooting, and understanding how data travels between devices. By the end of the lab, we should be able to build a basic network, connect devices successfully, and verify communication between them.
