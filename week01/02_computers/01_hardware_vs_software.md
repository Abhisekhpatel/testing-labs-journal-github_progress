# Part 1 – Hardware vs Software

## Explain Hardware
Hardware refers to every physical component that makes up a computer system — the parts you can actually see, touch, and hold. This includes the CPU (Central Processing Unit), which processes all instructions and acts as the brain of the machine; the RAM (Random Access Memory), which temporarily stores data that's actively being used so the processor can access it quickly; the hard drive or SSD, which holds all your files, programs, and the operating system permanently; the motherboard, which connects everything together; and peripherals like your keyboard, mouse, monitor, and speakers. Without hardware, there is simply nothing to run software on — it is the physical backbone of every computing device.
